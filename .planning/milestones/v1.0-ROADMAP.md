# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-15
**Phases:** 1-4
**Total Plans:** 4 plans

## Overview

MVP do sistema de clipping de vídeos YouTube com workflow multi-stage (candidatos → scoring → seleção → validação). Foco em política brasileira com IA para identificar momentos relevantes.

## Phases

### Phase 1: Workflow Core

**Goal:** Estrutura base do workflow multi-stage inspirado no OpusClip

**Plans:**

- [x] 01-01: Implement VideoClippingWorkflow class

**Details:** VideoClippingWorkflow com 6 stages: ANALYZE → CANDIDATES → SCORE → SELECT → VALIDATE → CUT. Estado persiste em .planning/workflows/. Validação de 30% threshold.

### Phase 2: Prompt Engineering

**Goal:** Melhorar precisão dos prompts LLM para timestamps

**Plans:**

- [x] 02-01: Optimize analyzer prompts

**Details:** Few-shot examples, timestamps exatos (1 casa decimal), chain-of-thought para reasoning sobre duração.

### Phase 3: UI & Multi-Profile

**Goal:** Dialog de workflow + suporte múltiplos profiles

**Plans:**

- [x] 03-01: AI Workflow main window integration

**Details:** WorkflowWindow com sidebar config, 4 stages (Upload → Analyze → Review → Export), candidato list com scores, multi-profile support.

### Phase 4: Advanced Scoring

**Goal:** Hook e Viral scores mais sofisticados

**Plans:**

- [x] 04-01: Advanced scoring implementation

**Details:** Hook score (pergunta inicial, declaração impactante), Viral score (citação compartilhável, estatística, polêmica), Duration score (proximidade do target).

## Milestone Summary

**Key Decisions:**

- Decision: Workflow multi-stage (Rationale: Separar geração de candidatos de avaliação permite precisão)
- Decision: Validação antes do corte (Rationale: Impedir Cutter de ajustar sozinho, workflow re-avalia)
- Decision: Transcript sampling em 50k chars (Rationale: Evitar timeout no LLM)

**Issues Resolved:**

- Fixed: `'Transcript' object has no attribute 'extract'` → `transcribe()`
- Fixed: analyzer syntax error (else indentation)
- Added: transcript sampling para evitar timeout
