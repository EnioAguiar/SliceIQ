# Plan: 03 - UI & Multi-Profile

## Overview

Criar workflow dialog inspirado no OpusClip com 5 stages: Upload → Analyze → Review → Configure → Export. Inclui redesign visual dark theme e suporte multi-profile.

## Requirements

- **MULTI-01:** Workflow pode gerar cortes para múltiplos profiles simultaneamente
- **MULTI-02:** Cada profile mantém métricas separadas
- **UI-01:** Dialog mostra progresso por stage
- **UI-02:** Lista de candidatos com scores
- **UI-03:** User pode remover/reordenar candidatos
- **UI-04:** Preview thumbnail do highlight

## Tasks

### Task 1: Criar WorkflowDialog class

**Actions:**
- Criar `ui/workflow_dialog.py` com QDialog
- Implementar 5 stages: UPLOAD, ANALYZE, REVIEW, CONFIGURE, EXPORT
- Progress bar no topo com círculos numerados
- Bottom buttons: Voltar/Próximo/Executar
- Navigation state machine (não permite pular stages)

**Verification:**
- Dialog abre sem erro
