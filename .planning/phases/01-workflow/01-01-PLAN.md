# Plan: VideoClippingWorkflow - OpusClip-like Multi-Stage AI Clipping

## Overview

Implementar workflow de clipping inspirado no OpusClip com geração de candidatos e avaliação em stages, seguindo o padrão GSD de workflow fases com estado persistente.

## Requirements

### From Discussion

- Workflow multi-stage como GSD (análise → candidatos → avaliação → seleção → corte)
- IA gera 2-3x mais candidatos que o quantity desejado
- Scoring multi-dimensional (hook, viral, duration compliance)
- Validação de duration_min/max antes do corte
- Estado persistente entre stages
- Suporte a múltiplos perfis por vídeo

### From Codebase Context

- `Analyzer.extract_highlights()` - precisa de refactor para multi-stage
- `Cutter.cut_video()` - já tem ajuste de duration, manter comportamento
- `Profile` model - já tem quantity, duration_min, duration_max
- LLM providers: minimax, gemini, ollama

## Phase 2: Stage Implementation

### Stage 1: ANALYZE

- Carregar transcrição do vídeo
- Analisar áudio ( peaks, silêncio, variação)
- Detectar topic boundaries
- Output: `state.transcript_segments`, `state.audio_features`

### Stage 2: GENERATE_CANDIDATES

- Chamar LLM com prompt expandido
- Request 2-3x candidates (se quantity=5, pedir 12-15)
- Prompt inclui duration constraints explícitos
- Output: `state.candidates`

### Stage 3: SCORE_EACH

- Segunda chamada LLM para avaliar candidatos
- Scoring dimensions: hook_score, viral_score, duration_score
- Calcular weighted total_score
- Output: `state.scored_candidates`

### Stage 4: RANK_AND_SELECT

- Ordenar por total_score descending
- Selecionar top `profile.quantity`
- Garantir não overlap entre highlights
- Output: `state.selected_highlights`

### Stage 5: VALIDATE

- Verificar cada highlight respeita duration_min/max
- Ajustar timestamps se necessário
- Filtrar scores abaixo de `profile.score_minimum`
- Output: `state.validated_highlights`

### Stage 6: CUT_AND_EXPORT

- Chamar Cutter para cada highlight válido
- Aplicar face_crop se profile.face_crop=True
- Output: lista de paths dos clips gerados

## Phase 3: Prompt Engineering

### Candidate Generation Prompt

```
Analise o transcript e identifique {quantity * 3} momentos potenciais para highlights.

REGRAS OBRIGATÓRIAS:
- Cada highlight deve ter entre {duration_min}s e {duration_max}s
- Timestamps devem ser momentos distintos, não consecutivos
- Priorizar momentos com hook forte (pergunta, declaração impactante)
- Priorizar momentos com alto potencial viral (engagement drivers)

Transcript:
{segments_text}

Retorne {quantity * 3} candidatos em formato JSON:
{{"candidates": [
  {{"start": float, "end": float, "score": int, "reason": str}}
]}}
```

### Scoring Prompt

```
Avalie cada candidato quanto a:
1. HOOK_SCORE (0-100): Quão forte é o início? Captura atenção?
2. VIRAL_SCORE (0-100): Potencial para viralizar/engajar?
3. DURATION_SCORE (0-100): Comply com {min}-{max}s range?

Candidatos:
{candidates_list}

Retorne JSON com scores:
{{"scored": [
  {{"start": float, "end": float, "hook_score": int, "viral_score": int, "duration_score": int}}
]}}
```

```python
def save_state(self, workflow_id: str):
    path = Path(f".planning/workflows/{workflow_id}/state.json")
    path.parent.mkdir(parents=True, exist_ok=True)
    with open(path, "w") as f:
        json.dump(self.state.__dict__, f, indent=2)

def load_state(self, workflow_id: str) -> WorkflowState:
    path = Path(f".planning/workflows/{workflow_id}/state.json")
    with open(path) as f:
        data = json.load(f)
    return WorkflowState(**data)
```
