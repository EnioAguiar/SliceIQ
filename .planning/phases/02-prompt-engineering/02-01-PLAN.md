# Plan: 02 - Prompt Engineering

## Overview

Otimizar prompts do Analyzer para melhorar precisão de timestamps. Implementar few-shot examples do próprio transcript, chain-of-thought implícito, e validação de duration.

## Requirements

- **PROMPT-01:** Few-shot examples (2-3 examples do transcript)
- **PROMPT-02:** Timestamps exatos (1 casa decimal)
- **PROMPT-03:** Chain-of-thought para reasoning
